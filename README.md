# Chaos-Assembly
A game Where you are trying to download an file but your browser trys to stop you with popups, ads and more currently there is the website download.com and download2.com for testing the trolling features of the game, also including some sites like google.com, amazon.com.
download.com moves the download button away from the mouse
download2.com spawns an popup over the download button

# Planned Next
More Creative Trolling Features, more websites, maybe acual assets, and much more ideas im going to have

# How to run
  Windows: 
  1: Download win-x64.zip from the newest release
  2: Unzip win-x64.zip
  3: Execute Chaos Assembly.exe

  Linux:
  1: Download linux-x64.zip from the newest release
  2: Unzip linux-x64.zip
  3: Execute Chaos Assembly
