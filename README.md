# Chaos-Assembly
A game Where you are trying to download an file but your browser trys to stop you with popups, ads and more currently there is the website download.com and download2.com for testing the trolling features of the game


# How to run
  Windows: 
  1: Unzip win-x64.zip
  2: Execute Chaos Assembly.exe

  Linux:
  1: Unzip linux-x64.zip
  2: Execute Chaos Assembly
